# Essence Registry

This registry contains only monster essences for which the reviewed material provides an actual mechanical description: stats, passive abilities, active abilities, or a clearly described mechanical effect.

Essences are linked back to their source monster. A monster that is only mentioned, used as an EXP reference, or associated with an essence without a described mechanical effect is intentionally omitted.

## Review rule

Do not create an essence entry merely because a monster drops an essence. The novel must provide at least one concrete property of that essence. When later chapter review reveals additional stats or skills, the corresponding entry should be extended rather than duplicated.
