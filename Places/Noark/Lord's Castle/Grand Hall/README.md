## Description
A grand hall deep inside the Noark fortress, equipped with a crystal-ball communication network used by the Lord to receive reports from his agents on the surface.

## Monsters
None recorded.

## Mechanics
- The crystal-ball network links the hall to agents outside; the Old Man Alchemist also uses it (ch. 205–206).

## Notable events
- ch. 205: The Lord hears Amelia's report; his treasurer estimates Noark can last 3 months (6 if starving) without the labyrinth, and the Lord orders the blockade kept until royal ID tags can be copied.
