# Dimensional Stele

| | |
|---|---|
| **Type** | landmark (stele / gate) |
| **Also known as** | 1st Floor Dimensional Stele |
| **First appearance** | ch. 790 |

## Description
A dimensional stele on the 1st floor that serves as the way down to the 1st Basement Floor. Explorers once crowded around it hoping a portal would open when the Floor Lord Verzak (Berzak) appeared.

## Monsters
None recorded.

## Mechanics
- Placing three Nameless Fragments (from the 3rd floor's Fragment Temple) on it opens access to the 1st Basement Floor. The fragments must be brought back down within 7 days, before the 1st floor closes (ch. 790).

## Notable events
- ch. 790: The stele is used to reach the 1st Basement Floor.
