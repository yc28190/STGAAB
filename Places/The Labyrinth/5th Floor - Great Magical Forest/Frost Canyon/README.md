# Frost Canyon

| | |
|---|---|
| **Type** | field |
| **Also known as** | 5th Floor - Frost Canyon |
| **First appearance** | ch. 205 |

## Description
An ice-attribute canyon field on the 5th floor, a frozen wasteland without snow. It is one of the four routes toward the 6th floor and a source of ice essences.

## Monsters
None recorded.

## Mechanics
- Drops many ice-attribute essences suited to Misha, including one Bjorn was aiming for (ch. 205).
- One of the four paths to the 6th floor (ch. 264).

## Notable events
- ch. 205: Named as Apple Nark's next hunting ground after the Hellfire Canyon.
- ch. 264: Bjorn skips it, having already obtained the essence he wanted there.
