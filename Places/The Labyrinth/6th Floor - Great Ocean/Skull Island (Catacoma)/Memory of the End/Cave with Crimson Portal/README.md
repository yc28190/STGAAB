# Cave with Crimson Portal

| | |
|---|---|
| **Type** | cave (portal site) |
| **Also known as** | Memory of the End – cave with crimson portal; entry portal cave |
| **First appearance** | ch. 799 |

## Description
A cave in the Memory of the End, unusual for being free of bones, that holds an ominous crimson portal.

It is the entry and exit point of the scenario: the mana wave Arta was tracking leads here.

## Monsters
None recorded.

## Mechanics
- The crimson portal is where the mana wave tracked by Arta ends (ch. 812).
- Leaving through the portal lifts the [Doomed] debuff, a fallback option the party considered (ch. 809).

## Notable events
- ch. 799: The party arrives through the portal.
- ch. 812–814: Human Arta panics on seeing a portal and asks whether this place is a labyrinth; he explains the Empire's Labyrinth Project and the dimensional collapse before being recalled to his own time.
