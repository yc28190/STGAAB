# Hidden Corridor (44-Torch Dead End)

| | |
|---|---|
| **Type** | corridor (hidden passage) |
| **Also known as** | Catacoma hidden corridor and 44-torch dead end; next chapter entrance |
| **First appearance** | ch. 797 |

## Description
A long straight corridor hidden behind a wall of the Catacoma Cave. Its entrance looks like any other dead end except that it holds exactly 44 wall torches. Behind it waits a blood-red portal, unlike the usual blue dimensional monoliths.

## Monsters
None recorded.

## Mechanics
- The next chapter after the Skull King connects directly with no door, so others can follow (ch. 797).
- Wherever exactly 44 wall torches stand is the entrance to the next stage: the Cursed One touches the wall, it slides open and a blood-red portal appears, announcing "The Cursed One has discovered a Memory of the End" (ch. 798).

## Notable events
- ch. 797–798: Bjorn has Raven cast Tier-4 [Mass Teleportation] to a junction in the corridor, then fills it with [Giant Form] and crushes a Golden Tree spy wearing No. 16 Ebony Emblem against the wall; she is interrogated and killed.
- ch. 798: Amelia stays behind with the Ebony Emblem to watch Golden Tree near the entrance.
