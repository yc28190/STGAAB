# Cliff Defense Point

| | |
|---|---|
| **Type** | defensive position |
| **Also known as** | Parune Cliff Defense Point |
| **First appearance** | ch. 274 |

## Description
A flat area on Parune Island backed by a cliff, so that only three sides need defending during the island's defence event.

## Monsters
- [[Guano Sea Serpent]] — wave 2 boss; drops a 4th-grade essence

## Mechanics
- Wave 2 opens with a monsoon-like downpour that cuts visibility, chills the body, turns the ground to mud, makes weapons slippery and strengthens water monsters (ch. 274).
- The Guano Sea Serpent targets the largest group first; the rain stops when it dies (ch. 274).

## Notable events
- ch. 274: The group holds this point for about 4 hours under Ersina's [Declaration of Evil's End] and kills the Guano Sea Serpent.
- ch. 274–275: Carmilla's drake attacks right afterwards.
