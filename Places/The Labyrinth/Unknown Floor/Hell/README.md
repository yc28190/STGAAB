## Description
A hidden field of the Labyrinth, mentioned only in passing, from which returning alive is practically impossible.

## Monsters
None recorded.

## Mechanics
- Breaking the wax seal of No. 444 Deadrius's Invitation inside the Labyrinth drags the user here; returning alive is practically impossible unless it is opened at one very specific spot (ch. 797).
