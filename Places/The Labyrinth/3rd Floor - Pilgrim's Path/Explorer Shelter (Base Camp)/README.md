# Explorer Shelter (Base Camp)

| | |
|---|---|
| **Type** | camp |
| **Also known as** | 3rd Floor Explorer Shelter; base camp |
| **First appearance** | ch. 459 |

## Description
A makeshift refuge set up by Bjorn on the 3rd floor during the Riakis crisis, where stranded lower-level explorers were gathered and protected. Its perimeter was guarded by barbarian warriors and volunteers.

## Monsters
- [[Chaos Spirit]] — roamed the floor while Riakis was active and threatened the camp

## Mechanics
- The perimeter was held by barbarian warriors and volunteers (ch. 459).
- Sheltering explorers earned Bjorn fame (ch. 459, 462).

## Notable events
- ch. 459: From day 13 until the floor closes, Bjorn gathers stranded explorers here (over 100, later over 1,000) while Erwen and Amelia search for stragglers; Lewis Siyur is put in charge when Riakis reappears.
- ch. 462: The rescued explorers arrive en masse and head off a fight with the Sawtooth Clan.
