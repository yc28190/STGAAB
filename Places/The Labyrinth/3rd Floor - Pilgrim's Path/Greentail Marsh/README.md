# Greentail Marsh

| | |
|---|---|
| **Type** | field |
| **Also known as** | Green-Tail Swamp; Greentail Marshes |
| **First appearance** | ch. 53 |

## Description
A 3rd-floor marshland whose soft, swampy ground preserves the tracks of parties that passed before. It lies between the Goblin Forest entrance and the Sculpture Temple and is home to the lizardmen.

## Monsters
- [[Lizardman]] — the marsh's main inhabitants

## Mechanics
- About six days' travel from the Orc Colony (ch. 53).
- Lies between the Goblin Forest entrance and the Sculpture Temple (ch. 505).
- A dead-end path leads to the Fragmented Temple (ch. 789).

## Notable events
- ch. 53: Misha suggests it as an alternative hunting ground; it is rejected as too far.
- ch. 505: Bjorn's route passes through on the way to the Sculpture Temple.
- ch. 789: Tracks show a team heading toward the Fragmented Shrine instead of the 4th floor.
