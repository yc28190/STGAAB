## Description
A 3rd-floor location reached by a dead-end path in the Greentail Marsh. Players know it as the route for obtaining the Nameless Fragments that unlock the hidden basement floor of the labyrinth.

## Monsters
None recorded.

## Mechanics
- Named on the community board as the route for the fragments that unlock B1; the statues that drop them appear on the 3rd floor (ch. 544–545).
- Source of the three Nameless Fragments needed for the Basement 1st Floor (ch. 790).
- Reached by a dead-end path off the Greentail Marsh (ch. 789).

## Notable events
- ch. 789: Tracks in the Greentail Marsh show a team heading toward this shrine instead of the 4th floor.
