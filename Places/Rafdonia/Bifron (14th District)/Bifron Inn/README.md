# Bifron Inn

| | |
|---|---|
| **Type** | building (inn / tavern) |
| **Also known as** | "the best place in the neighborhood" |
| **First appearance** | ch. 192 |

## Description
A bug-infested-looking inn with a bar on the ground floor, rooms upstairs and a rusty bell over the door. Tough-looking men and women in shabby clothes drink inside.

## Monsters
None recorded.

## Mechanics
- 50 stones a night and 250 stones a meal (bread and white soup), paid in advance (ch. 192).

## Notable events
- ch. 192: Working with the Western Union, the bartender and a local boy serve Bjorn drugged food; he sees through the trap.
