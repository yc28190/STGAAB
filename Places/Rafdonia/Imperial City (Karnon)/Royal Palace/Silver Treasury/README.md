# Silver Treasury

| | |
|---|---|
| **Type** | building (royal vault) |
| **Also known as** | — |
| **First appearance** | ch. 233 |

## Description
A royal treasure vault one rank below the Golden Treasury. It stores 4th-grade essences and equipment of similar value.

## Monsters
None recorded.

## Mechanics
- It holds 4th-grade essences and items of similar value (ch. 233, 241).

## Notable events
- ch. 233: Melter Pend is allowed one essence and one item from it.
- ch. 241–242: Erwen picks her reward here, a core essence for bow-wielding fairies recommended by Bjorn, and rests for a while after absorbing it. The other party members receive 5th-grade essences.
