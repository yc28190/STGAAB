# Secret Chamber (Revival Ring)

| | |
|---|---|
| **Type** | room (secret chamber) |
| **Also known as** | Royal Palace secret location; secret chamber in the palace |
| **First appearance** | ch. 769 |

## Description
An unseen location inside the Royal Palace where the royal revival ring sends its wearer. The Marquis visited it once and believed it holds a vast secret. He makes clear it is not the chamber beneath the palace that Bjorn saw earlier.

## Monsters
None recorded.

## Mechanics
- A black ring, a royal treasure, appeared on the Marquis's ring finger. When it activates, whether forced or voluntary and including on death within the city, it carries the wearer to this place in the palace (ch. 769).
- The ring is recognizable, so it should not be worn openly. Bjorn stores it in subspace (ch. 769).

## Notable events
- ch. 769: Bjorn obtains the ring and learns where it leads.
