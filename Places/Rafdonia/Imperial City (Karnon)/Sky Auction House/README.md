# Sky Auction House

| | |
|---|---|
| **Type** | building (auction house) |
| **Also known as** | Celestial Auction House; Sky Auction |
| **First appearance** | ch. 157 |

## Description
An exclusive auction house for nobles in Karnon, and the usual venue for the rarest numbered items. It is only ever mentioned, never visited.

## Monsters
None recorded.

## Mechanics
- Double Numbered Items usually appear only here (ch. 300).
- Lots are kept secret until the day before the auction (ch. 331).
- It introduced anonymous bidding (ch. 335).

## Notable events
- ch. 157–158: A Double Numbered Item (No. 11–99) is to be auctioned here the following month. Fox later reveals which item it is.
- ch. 784: After the Urae strike on the Palace of Glory, no one is left to attend its auctions.
