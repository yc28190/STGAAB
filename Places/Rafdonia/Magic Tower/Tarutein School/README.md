# Tarutein School

| | |
|---|---|

| **Also known as** | Tarutein |
| **First appearance** | ch. 90 |

## Description
A Magic Tower school that studies the labyrinth and dimensional magic. It has little contact with Raven's Artemion School.

## Monsters
None recorded.

## Mechanics
None recorded.

## Notable events
- ch. 90: Its mage Chernal Pergan supposedly predicts a dimensional collapse.
- ch. 93: According to Ghostbusters, the school's master planted the rumor to cut the number of explorers going in, for an experiment. The royal family is expected to deny it, since fewer explorers means fewer magic stones.
