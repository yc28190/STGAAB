# Magic Tower Plaza

| | |
|---|---|
| **Type** | plaza |
| **Also known as** | Mage Tower Plaza; the plaza in front of the Mage Tower |

## Description
A wide plaza at the foot of the Magic Tower's black spire. During the barbarian march it was packed with citizens, and hundreds of mages lined up facing the barbarians.
