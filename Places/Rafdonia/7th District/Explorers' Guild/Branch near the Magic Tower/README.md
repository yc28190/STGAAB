# Branch near the Magic Tower

| | |
|---|---|
| **Type** | building (guild branch) |
| **Also known as** | Adventurers' Guild Branch near the Tower |
| **First appearance** | ch. 45 |

## Description
A branch office of the Adventurers' Guild near the Magic Tower, where staff member Terbes handles party recruitment.

## Monsters
None recorded.

## Mechanics
- Staff look up recruitment notices matching an adventurer's criteria and pass on applications; meetings are arranged by letter (ch. 45–47).

## Notable events
- ch. 45–46: Bjorn applies here to Hikurod Murad's "Third Floor Exploration" team.
