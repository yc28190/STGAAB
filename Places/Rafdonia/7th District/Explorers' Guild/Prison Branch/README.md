# Prison Branch

| | |

## Description
A three-storey Explorers' Guild branch building. The ground floor has a counter, administrative staff and crowds of adventurers, with numbered tickets; a 2nd-floor hallway with a railing overlooks it and holds a private VIP room. The 3rd floor has old-fashioned offices with wooden furniture and plaques, the branch manager's office with sofas and an expensive desk, and a terrace above the street. Beneath it lies an underground prison for suspected pillagers. Branch Manager Peta (mustached) and employee Odrian work here.

## Monsters
None recorded.

## Mechanics
- A thick double door at the top of a long staircase separates the underground prison from the ground floor, so noise below cannot be heard upstairs (ch. 38).
- Wizards can land on the 3rd-floor terrace from the air; Magic Tower wizards come through the tower's warp gate and walk about ten minutes (ch. 39).
- Suspected marauders are held below while a mage checks statements with a spell (ch. 119).
- Clan registration needs paperwork and a minimum roster; Floor Lord raid requests are filed here and broadcast to every branch (ch. 442, 467).

## Notable events
- ch. 38–41: Bjorn breaks out of the prison and takes a hostage; his name is cleared by Raven's "image of remembrance" recording before a crowd.
- ch. 119–123: Karon is cleared as acting in self-defense; Peta passes on Julian Urbans's request for a meeting.
- ch. 442–446: Clan Anabada registers with Bjorn as leader (Emily Raines, Ainar Frenelin, Auyen Lokrob; Erwen joins later).
- ch. 467: The branch manager handles the raid request on Dreadfear, the 1st-floor Floor Lord; a five-man clear would be only the tenth in history.
