# Cheap Explorers' Tavern

| | |
|---|---|
| **Type** | shop (tavern) |
| **Also known as** | Cheap Explorers' Tavern (7th District) |
| **First appearance** | ch. 433 |

## Description
A crowded, low-end explorer bar in the 7th District with cheap liquor, empty bottles strewn across the floor, and a rowdy atmosphere where fights break out over nothing. Gossipers sell news to explorers for coins.

## Monsters
None recorded.

## Mechanics
None recorded.

## Notable events
- ch. 433: A newsboy sells an "extra" announcing that Bjorn Yandel is alive; Ainar Frenelin overhears, pays the boy 10,000 stones and leaves without paying for her drinks.
