# Old Leathlas Temple

| | |
|---|---|
| **Type** | building (temple) |
| **Also known as** | Reatlas Temple (7th District); old temple of the Reatlas faith |
| **First appearance** | ch. 624 |

## Description
An old Leathlas (Reatlas) temple in the 7th District with a two-level underground prison: ordinary explorers on the first basement level, priests and mages on the second. During the Noark occupation it was used to hold hostages.

## Monsters
None recorded.

## Mechanics
- Lightly guarded; prisoners were held with essence-sealing shackles, which Bjorn crushed by hand after bending the bars (ch. 624).

## Notable events
- ch. 624: The first target of Bjorn's hostage rescue; the freed bishops remove his Orc Hero essence so he can absorb a new custom essence.
