## Description
A plain, empty building with no windows and only a sofa in one corner, rented by Bersil Gowland for secret meetings.

## Monsters
None recorded.

## Mechanics
- Protected by voice-control magic and a mana-detection field set up by Bersil (ch. 446).

## Notable events
- ch. 446–447: The Ice Rock expedition survivors (Meland Kaislan, Liris Marone, James Kala, Sven Parab and Bersil) reunite here. They open the Rose Knights' secret subspace pockets: cash, fake IDs, Lete's Blessing memory pills, acid, a list of royal spies and the royal order to eliminate the expedition. They plan to join the clan at staggered times.
