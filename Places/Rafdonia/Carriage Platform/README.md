# Carriage Platform

| | |
|---|---|
| **Type** | transport station |
| **Also known as** | platform; shared platform |
| **First appearance** | ch. 47 |

## Description
A departure point for the shared ten-seat carriages that connect Rafdonia's districts. It is the city's main public transport.

## Monsters
None recorded.

## Mechanics
- A seat costs 250 stones per person; barbarians have to pay for two seats (ch. 47).
- Carriages link the districts and stop running at night (ch. 72).

## Notable events
- ch. 74: Misha takes a carriage to visit her family, the Kaltsteins of the Red Cat tribe.

## Chapters
47, 72, 74
