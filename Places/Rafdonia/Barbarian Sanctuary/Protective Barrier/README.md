# Protective Barrier

| | |
|---|---|
| **Type** | barrier |
| **Also known as** | invisible wall; the barrier |
| **First appearance** | ch. 248 |

## Description
An invisible wall about an hour's brisk walk beyond the Sanctuary campsite. It marks the furthest point anyone may go, yet the forest is plainly visible carrying on beyond it.

## Monsters
None recorded.

## Mechanics
- It feels solid to the touch. The barbarians believe everyone would die if it were damaged (ch. 248).

## Notable events
- ch. 248: Doubting what lies outside after his time in Bifron, Bjorn comes to look at the barrier. The one-eyed shaman, holding a funeral nearby, warns him that everything has its order and it is not yet time for him to wonder what lies beyond.
