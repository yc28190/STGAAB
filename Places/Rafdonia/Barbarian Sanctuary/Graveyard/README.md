# Graveyard

| | |
|---|---|
| **Type** | cemetery |
| **Also known as** | Barbarian Sanctuary Graveyard; cemetery |
| **First appearance** | ch. 774 |

## Description
A gloomy graveyard in the Barbarian Sanctuary, swept by a cold night wind. Its headstones carry birth and death dates, including those of Brown Rotmiller, Versil Gowland and James Carla.

## Monsters
None recorded.

## Mechanics
None recorded.

## Notable events
- ch. 774: There is no burial land left in Rafdonia, so James Carla's family agrees to bury him here.
- ch. 775, 777: Bjorn, Hikurod, Shabin and Sven visit to mourn.
- ch. 782: Vekta's prize house is to be built on a site beside the cemetery.
