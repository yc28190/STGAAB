# Vekta's House Site

| | |
|---|---|
| **Type** | building site |
| **Also known as** | Vekta's house site (near the cemetery) |
| **First appearance** | ch. 782 |

## Description
A cool spot beside the Sanctuary cemetery where the house Vekta won is to be built. Housing is scarce, so most barbarians live communally inside the Sanctuary, and real estate there is now being developed.

## Notable events
- ch. 781–782: After winning the drinking duel, Vekta camps on the site until his house is built.
