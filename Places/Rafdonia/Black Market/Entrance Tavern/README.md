# Entrance Tavern

| | |
|---|---|
| **Type** | building (tavern / entrance) |
| **Also known as** | Black Market Entrance Tavern; dilapidated tavern in a back alley |
| **First appearance** | ch. 492 |

## Description
A crumbling tavern in a Commelby back alley that never opens, with a rusty sign barely hanging on. Inside it looks like a building site, all dust and debris except a trail of footprints leading to a basement staircase. At the bottom is an unguarded steel door with only a wall behind it.

## Monsters
None recorded.

## Mechanics
- Beside the door is a slot: insert a magic stone and swipe your ID card to be teleported into the Black Market. The steel door is a decoy (ch. 492).
- It is one of hundreds of such entrances around the city (ch. 492).

## Notable events
- ch. 492: Out of curiosity Bjorn rips off the door, setting off the guards.
