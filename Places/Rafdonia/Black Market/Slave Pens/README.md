# Slave Pens

| | |
|---|---|
| **Type** | dungeon (cages) |
| **Also known as** | Black Market Slave Pens; cages |
| **First appearance** | ch. 493 |

## Description
A dimly lit level of the Black Market lined with cages holding demi-humans of many races. All are tattooed in the same place, and most stare blankly as if brainwashed.

## Monsters
None recorded.

## Mechanics
None recorded.

## Notable events
- ch. 493: Bjorn smashes through the ceiling to reach the pens. Slavery has been illegal in Rafdonia for about 100 years. The prisoners include a boy enslaved for his dead mother's debts and a fairy named Riley. The slaves are freed afterwards.
