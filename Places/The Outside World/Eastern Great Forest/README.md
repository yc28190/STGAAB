# Eastern Great Forest

| | |
|---|---|
| **Type** | region (forest) |
| **Also known as** | southeast of the Great Forest |

## Description
A peaceful-looking forest outside Rafdonia's walls; the whole area around the walls is dense forest and hard going on foot.

Its name comes from Bjorn comparing the real land with the Dark Continent map; Ibaekho clarified that it is more precisely the southeast part of the Great Forest.

## Monsters
None recorded.

## Mechanics
- About two days' walk from the cave mouth to Rafdonia's wall (ch. 661).

## Notable events
- ch. 661–665: Bjorn emerges here from the underground passage and later identifies the region with Ibaekho's help.
