| | |

## Notes (1re passe)
Créature duveteuse de l'île-Bibliothèque qui ne parle que la langue ancienne ; un double amnésique dans la faille ; Bjorn l'emmène, en fait un ami ; ancien cobaye de Panthelion, mort dans les bras d'une sorcière ; ses souvenirs mènent à la carte métallique ; rejette le nom de Marx ; ramené à l'île-Bibliothèque, ne peut pas quitter le sous-sol 1.
