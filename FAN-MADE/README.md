# FAN-MADE

Original fan fiction set in the world of *Surviving the Game as a Barbarian*. The prose is written from scratch: it borrows the setting (the game *Dungeon and Stone*, Rafdonia, the labyrinth, the "cheat version" played by the other evil spirits) but not the text of the novel.

## Eric Dupont — the dwarf
Eric Dupont, 32, from France, played the original game for 8 years as a dwarf tank. He can reach the 10th floor reliably but never found the pattern to open the Abyss Door, so he finally beat the game with the cheat version, using only the *Experience ×2* toggle. He wakes up in Rafdonia in the body of a 20-year-old dwarf.
