## Conventions

- **Une page = un sujet**, nommée en `snake_case` : `bjorn_yandel.md`, `labyrinth_floor_1.md`.
- Partir d'un modèle dans [`_templates/`](_templates/).
- Lier les pages entre elles avec des liens relatifs : `[Bjorn](../character/bjorn_yandel.md)`.
- Toujours citer la source : `(ch. 123)`.
- Marquer les informations incertaines avec `❓`.
